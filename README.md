# TFG-Memoria

This repository contains the report for a Final Degree Project (TFG) written in LaTeX. It is intended as a read-only repository, with the main content organized into chapters, appendices, and supporting resources.

## Main structure

- `main.tex` - Main entry point for compiling the document.
- `estilo.tex` - LaTeX style and configuration settings.
- `bibliografia.bib` - Bibliography database used in the report.
- `portada/` - Cover pages, index, summary, acronyms, and acknowledgments.
- `capitulos/` - Report chapters from introduction to future work.
- `apendices/` - Appendices, including references to project repositories and code.
- `figuras/` - Figures and diagrams organized by chapter.
- `recursos/` - Additional support files and data, such as code examples and planning tables.

## Included chapters

The document includes, among others, the following chapters:

- Introduction
- Justification
- State of the art
- Roadmap
- Feasibility study
- Strategy
- Design and scripts
- Configuration and execution
- Results
- Planning
- Budget
- Sustainability
- Conclusions
- Future work

## Appendices

The appendices contain supplementary material relevant to the project:

- `A_githubRepository.tex` - Information related to the GitHub repository.
- `B_codigos.tex` - References to code samples or examples.
- `C_RepositoriosProyecto.tex` - Project repositories and resources.

## Usage

This repository is intended for reviewing the report contents. To compile the document locally, use the provided `Makefile` with a compatible LaTeX distribution.

Install the required LaTeX dependencies first:

Then compile the project:

```sh
make
```

## Purpose

The repository documents a complete academic project, including planning, design, results, and feasibility analysis. It serves as a reference for a LaTeX-based Final Degree Project report.
